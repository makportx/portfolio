Project Overview

A dynamic, multi-page personal portfolio web application built using React, Node.js, and MongoDB. Features an embedded interactive conversational AI assistant capable of answering visitor inquiries about skills, experience, and projects in real time.

Technical Implementation & Architecture

### Architecture & Features: - **Modern Frontend**: Developed with React components, featuring responsive layouts, fluid transitions, and fast page navigation. - **Backend API**: RESTful API endpoints powered by Node.js and Express for serving dynamic project data and handling contact inquiries. - **MongoDB Database**: Document storage for portfolio items, user messages, and configuration. - **Embedded AI Assistant**: Custom interactive conversational interface trained on resume context to answer visitor queries immediately without waiting for an email response. ### Tech Stack: React, Node.js, Express, MongoDB, Tailwind CSS, JavaScript.
